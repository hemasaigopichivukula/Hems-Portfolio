# Hems Portfolio Website

Personal portfolio website built with React (Vite) on the frontend and Express on the backend.

## Tech Stack

- React + TypeScript
- Vite
- Express
- Tailwind CSS

## Prerequisites

- Node.js 18+ (recommended)
- npm

## Run Locally (View the Website)

1. Open a terminal in this repository root.
2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

4. Open your browser and go to:

   [http://localhost:5000](http://localhost:5000)

The app and API are served from the same server during development.

## Windows Instructions (PowerShell or Command Prompt)

1. Open **PowerShell** or **Command Prompt**.
2. Go to this project folder:

   ```powershell
   cd "C:\Users\hemas\Desktop\mywebsite\Hems-Portfolio"
   ```

3. Install dependencies:

   ```powershell
   npm install
   ```

4. Start the app:

   ```powershell
   npm run dev
   ```

5. Open this URL in your browser:

   [http://localhost:5000](http://localhost:5000)

If PowerShell blocks npm scripts, run this once in PowerShell and try again:

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

## Production Build

Build and run the production version:

```bash
npm run build
npm run start
```

Then open [http://localhost:5000](http://localhost:5000).

## Useful Scripts

- `npm run dev` - run in development mode
- `npm run build` - create production build
- `npm run start` - run built app
- `npm run check` - run TypeScript checks
